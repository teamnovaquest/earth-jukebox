# Use of AI in Earth Jukebox

Team NovaQuest used AI tools while building Earth Jukebox. This file lists where and how, so judges and visitors can see it clearly.

## AI tools used to build the project
- **Claude (Anthropic):** helped design and write the website's code and data handling, debug it, and draft texts, including the papers, guides, descriptions and the spoken-guide translations.
- **ElevenLabs:** AI voice for the narration in our videos.
-  **Google Gemini (Nano Banana 2):** generated our team logo.

## AI built into the website
- **Google Gemini (Gemini API):** powers the SI assistant, Analytics, the Compare overview and the optional research essay (with Google Search grounding). Gemini-written text is marked as such on the site and in reports.
- **Google Translate:** translates the website's text into other languages on request.
- **Text-to-speech voices:** Microsoft Clipchamp text-to-speech (voice "Amanda Multilingual") for the recorded spoken guides, and the open-source Piper voice "hfc_female" (via vits-web) for spoken audio reports in the browser.

## What is not AI
- **The data:** every number, map and picture comes from NASA and the other sources listed in the README and in each report. Nothing is generated by AI.
- **The SI's rhythm model:** it is classical statistics written in our own code (a permutation-tested least-squares spectrum and harmonic regression). It runs in the visitor's browser and does not call any AI service.
- **The music:** composed in code from the data.

## The team's role
Team NovaQuest chose the idea, developed and programmed the website, directed the design and features, decided what the site should do, and reviewed and tested the results, including the accuracy checks against NASA's servers.
